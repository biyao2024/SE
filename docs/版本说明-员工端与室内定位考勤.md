# 员工端与室内定位考勤

员工使用统一登录页，按账号角色进入独立工作台，查看个人资料、人脸录入状态、今日及历史考勤，办理请假和补卡。管理员通过“考勤方式与地点”配置人脸、定位或两种方式任选，并维护启用地点和半径。

本版在员工端与定位考勤功能之上改进室内定位：不再拿到第一条位置就结束，改为最多20秒采样并选取设备报告的最佳有效位置。结束、拒绝权限、取消或离开页面后停止监听。估计误差较大的地点坐标需管理员核对确认；不会通过平均坐标或改写误差来声称精度提高。

地点允许误差默认100米，可配置1–500米，实际限制同时受考勤半径一半约束。以估计误差137米为例，仅在管理员明确配置至少150米误差、300米半径，且估计坐标确实落在范围内时才可通过。旧地点的默认设置保留，扩大容差无法保证区分相邻房间或楼栋。

定位打卡使用本人登录账号和服务器时间，并校验范围、位置时效、工作日、打卡时段及重复请求。定位进入正式考勤；原全天测试开关只用于人脸测试。人脸诊断、动态验证及测试记录隔离继续保留。

另修复Windows PowerShell读取不带BOM的UTF-8进程记录时中文路径损坏的问题；进程归属、可执行路径和启动时间校验保留。

## 验证

- 后端58项测试通过，包括员工数据隔离、管理员配置权限、时效和范围、重复请求与混合打卡记录，以及默认拒绝/显式配置后接受137米估计误差。
- 前端24项测试通过，覆盖范围、时间窗口及连续采样改善、低精度保留、取消、权限拒绝和无效位置过滤。
- TypeScript检查及Vite生产构建通过；打包仍有既有大资源块提示。
- 本机已启动并确认API可访问、V3/V4迁移成功、算法模型和人员库就绪。上述检查不代替真实手机定位、室内到岗范围或识别准确率验收。

## 升级与恢复

本版包含V3地点表和定位事件字段迁移，以及V4地点误差上限迁移；更新前请停机备份数据库和对应JAR。构建后重启后端，前端同步更新，无需更换模型或重新录入人脸。已有接口省略地点误差字段时，新建默认100米，修改保留旧设置。

定位和摄像头权限由访问设备的浏览器提供。电脑本机使用localhost，手机沿用已信任的HTTPS入口。已有账号、密钥、模型及依赖继续使用；敏感配置和业务数据不随源码发布。回退数据库时同时恢复对应代码和JAR，并先保留升级后需要的数据。
