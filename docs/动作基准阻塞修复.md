# 动作基准阻塞修复（本机试用已确认）

诊断样本显示：身份分数和首帧一致性通过时，左右自然闭眼系数常在0.21～0.26。旧策略要求双方不超过0.20，导致自然基准计数反复清零；即使偶尔进入动作，剩余35秒预算也可能不足。单帧处理约1.3～1.5秒，不能按6fps理解帧计数。

## 本次改动

- 自然睁眼上限从0.20调整为0.30。基准、眨眼后恢复、最终收尾共用同一常量，避免只修一个阶段。
- 闭眼下限仍为0.55，要求双眼都达到；自然闭嘴上限0.15、张嘴下限0.35保持。开放/闭合门槛分离，仍要求动作变化与恢复。
- 初始已连续两帧建立自然状态后，直接进入第一个动作的执行阶段，不再次重复两帧自然状态。第二个动作仍检查对应自然状态；最后仍检查三帧自然状态。
- 眨眼提示明确为闭眼约2秒再睁开；张嘴提示保持约3秒并等闭嘴提示。
- 管理员诊断展示自然基准帧数、完成动作数，以及当前四项动作门槛，方便识别卡在哪一阶段。

身份相似度及分差配置不修改，不跳过身份检查。本次基准修复保留身份及资源限制；最终版本的采集预算已在后续CPU改进中统一为50秒，80帧、12MiB和60秒会话边界不变，见 [CPU推理与动作时间预算](CPU推理与动作时间预算.md)。静态自然画面仍不能完成动作；持续闭眼或模糊画面不能当作自然基准。

0.30是结合当前诊断数据提出的测试工作点，不是经过不同人群验证的正式校准结论。应在管理员测试模式中验证本人动作、未录入人员及静态照片，并记录结果；本机试用已由使用者确认后发布；保留针对不同人员及设备的验证要求。
