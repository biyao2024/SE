## 修复与边界

真实联调发现 JDK HTTP 客户端默认尝试 h2c 升级，Uvicorn HTTP/1.1 接口收到空请求体，导致人员库同步返回 422。最小复现确认：同一请求，默认协议返回 422，明确 HTTP/1.1 返回 200。后端内部 REST 客户端据此固定 HTTP/1.1；不需要改变文档中的库版本。

联调还发现打卡会话创建直接读取 Spring 事务代理中的时钟字段，触发空指针。改为通过服务方法获取时区，并增加使用真实 Spring 代理的会话创建回归测试。

还补齐了真实模型诊断、摄像头实验采集、评分 CSV 生成和独立样本校准工具；前端处理了采集重复点击、迟到回调及未就绪状态。默认阈值仍属于工程初值，未伪造校准结果。

原计划允许演示时手动勾选默认参数放行。本次调整为正式业务环境继续保持校准门槛；隔离测试中使用的配置夹具单独说明，不写回业务数据库。这样界面上的“已校准”保持原本含义。
