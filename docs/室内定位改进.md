# 室内定位与地点误差配置

浏览器报告的±137米是估计误差，不是员工距地点137米。软件不能把此值改小后当成准确定位，也不能保证区分相邻房间。

## 本次处理

- 点击定位后最多采样20秒，保留浏览器报告的最佳有效位置；达到目标精度时提前结束。采样中显示当前最佳误差，不平均坐标或虚构更小的精度。
- 权限拒绝、结束采样、取消、页面离开和地点弹窗关闭时停止监听。过期、未来超时、无效坐标不能参与选取，低精度结果到期后仍以原始误差返回。
- 管理员设置地点时，500米内的估计结果可填入表单。误差较大时展示提示，保存前要求核对确认，或手动修正WGS84经纬度。该确认只表示管理员选择地点坐标，不代表员工定位通过。
- 每个地点新增“允许定位误差”，默认100米，可设置1–500米。实际限制为该设置、500米系统上限、考勤半径一半三者中的最小值；默认旧地点行为不变。
- 员工端与后端使用同一限制，后端仍验证范围、登录身份、位置时效、工作日、时间窗口及重复请求。

## ±137米的室内场景

若实际考勤场地允许300米范围，管理员可以将该地点的半径设为300米，允许误差设为150米。此时估计坐标在范围内且误差为137米可通过；半径200米时实际误差上限仍为100米，不能通过。坐标在范围外不会因误差较大而扩大范围。

这是一项接受范围更宽的位置策略，应按真实场地选择；如需房间或楼栋级精度，应使用能够提供相应位置精度的设备或其他考勤方式。不会自动扩大已保存地点或改动员工记录。

## 升级

V4迁移只增加地点的 `max_accuracy_meters` 字段，默认100。已有接口省略该字段时，新建地点使用100，修改地点保留旧设置；无需更换模型或重新录入人脸。回退旧数据库时应同时恢复对应代码和JAR，并先保留升级后需要的数据。
