# 验收清单与实验记录模板

此表是待执行的完整验收清单。自动化证据另见 `validation.md`；未勾选项表示尚未形成针对该部署环境的验收证据，不意味着代码中一定缺少对应功能。

## 业务

- [ ] 普通员工无法访问管理员接口，无法通过改ID或筛选参数读取他人数据。
- [ ] 停用员工的现有会话立即失效，原浏览器仍可重新获取CSRF并换账号登录。
- [ ] 首次登录须改密码，未登录/已退出会话被拒绝，写操作缺CSRF时被拒绝。
- [ ] 未授权、到期、撤销的设备无法创建或继续有效打卡会话。
- [ ] 同一会话重复提交最多产生一条成功事件；30秒内同类型重复不新增事件。
- [ ] 首次签到/最后签退、09:05与17:55、窗口边界和跨日期行为正确。
- [ ] 迟到与早退可并存；日终前待打卡、日终后缺卡/缺勤正确切换。
- [ ] 请假不计缺勤，非工作日不计算加班，统计只计员工有效在职期间。
- [ ] 规则次日生效、未来日历限制、历史规则快照均不破坏历史日报。
- [ ] 整天请假重叠、与有效打卡/补卡冲突被拒绝。
- [ ] 补卡7天范围、窗口约束、同类型待审批唯一性正确。
- [ ] 审批并发只生效一次，不能审批本人申请，人工修正不覆盖原始事件。
- [ ] 服务重启补算遗漏日报，历史查询、月报与Excel一致。

## 模型、动作及故障

- [ ] 模型SHA-256与记录一致，来源和许可已确认。
- [ ] 三姿态录入单人/质量/身份一致性/疑似重复绑定正确。
- [ ] 录入、更换、停用、删除模板后人员库版本同步；同步失败阻断打卡。
- [ ] 无人、多人、低质量、未知人员、身份切换有明确结果。
- [ ] 单帧体积、80帧上限、12MB累计体积、12秒动作时限、60秒会话时限可触发拒绝。
- [ ] 关闭动作记为SKIPPED；开启需完整眨眼与张嘴、顺序正确、全程身份一致。
- [ ] 修改前端通过标记、提交他人身份、重放旧会话、无效内部密钥均不能绕过。
- [ ] 两设备并发可用，第三设备得到繁忙提示；模型启动/停止/超时不能生成成功考勤。
- [ ] 摄像头拒绝授权、占用、断网、切换页面释放设备符合预期。
- [ ] MySQL8.4实际启动迁移通过，数据库失败不能返回成功。
- [ ] 在独立恢复环境验证账号、考勤和加密模板均可用。

## 独立校准与测试

建议10—20位知情参与者，每人3张现场录入图像。校准与正式测试必须使用不同采集数据；加入未录入人员，分别记录正常光照、偏暗、眼镜、距离和轻微侧脸。相似度与候选分差阈值仅根据校准集确定，然后冻结参数再跑独立测试。

每条实验记录至少包含：匿名人员编号、采集场景、真值是否已录入、开关状态、模型SHA-256、配置版本、是否正确识别/误接纳/拒绝、动作结果、失败原因、耗时、设备与时间。不要在公开论文附件中放置原始面部图像、可逆身份映射或完整特征向量。
