# 知行 · 考勤前端

Vue 3 + TypeScript + Vite + Element Plus + Pinia + Vue Router + ECharts，实现管理员、员工和公共打卡设备三个入口。界面语言为中文，适配桌面和手机。

## 本地运行

本次交付对齐《另一台电脑环境清单与执行计划.md》：**Node.js 24.18.0、pnpm 11.25.0**。`package.json` 的 `engines` 和 `packageManager` 均固定这两个版本，安装前先确认版本，不能用另一套 Node 构建后声称完成目标环境验证。

```powershell
node --version
pnpm.cmd --version
pnpm.cmd install --frozen-lockfile
pnpm.cmd dev
```

应分别显示 `v24.18.0` 和 `11.25.0`。如果复制来的 `node_modules` 属于另一套 pnpm，请在保留原项目的干净副本中重新安装；不要在正在提供服务的目录强行删除或替换依赖。配置文件包括 `package.json`、`pnpm-lock.yaml`、`pnpm-workspace.yaml` 和 `.npmrc`，交付时应一起保留。

`pnpm-workspace.yaml` 只允许锁定的 **esbuild@0.28.2** 执行依赖构建脚本，未知依赖脚本会让安装失败。本项目无需选择“批准全部脚本”，也不应通过删除锁文件、关闭证书验证或放宽脚本权限来绕过安装错误。

运行脚本前若报告 `ERR_PNPM_VERIFY_DEPS_BEFORE_RUN`，应先在同一终端确认 Node/pnpm 版本，再显式执行 `pnpm.cmd install --frozen-lockfile`。项目禁止在 `pnpm build/test` 期间隐式重装依赖，避免调用到 PATH 中另一套 Node 或 pnpm。

打开 `http://localhost:5173`。Vite 将 `/api`（包括 WebSocket）代理到 `http://127.0.0.1:8080`。摄像头在本机 `localhost` 下可用；手机及其他局域网设备必须通过安装并信任证书的 HTTPS 入口访问。部署配置见项目根目录 Readme.md。

```powershell
pnpm.cmd typecheck
pnpm.cmd test
pnpm.cmd build
```

构建产物为 `dist/`，由 Nginx 提供静态服务。所有前端路由需要回退到 `index.html`。

## 功能入口

| 路径 | 功能 |
| --- | --- |
| `/login` | 账号登录 |
| `/` | 真实 API 数据的出勤概览与统计图 |
| `/attendance` | 考勤筛选、分页与 Excel 下载 |
| `/requests` | 请假/补卡申请、撤销、管理员审批 |
| `/employees` | 人员建档、部门管理、现场人脸采集、删除模板 |
| `/devices` | 当前浏览器授权和设备撤销 |
| `/rules` | 固定班次、未来工作日历例外 |
| `/settings` | 服务健康、人员库同步、识别与动作配置 |
| `/audit` | 操作审计记录 |
| `/password` | 修改密码，首次登录强制进入 |
| `/kiosk` | 无员工账号登录的公共刷脸打卡（需要设备授权） |

员工仅能进入本人工作台、考勤和申请。管理员页受路由保护；真正的授权、数据隔离与防自审必须由业务后端执行。

## 相机与数据处理

- 人脸录入仅支持摄像头现场采集正脸、轻微左转、轻微右转三张，必须勾选单独同意；没有照片上传入口。
- 录入按次串行采集，避免连续点击提交多张同一帧；宽屏或竖屏相机居中裁剪到 4:3，不拉伸面部比例。
- 打卡使用 640 × 480 JPEG 二进制 WebSocket 帧，约每秒 6 帧，单帧最多 200 KiB，最长 12 秒，并限制帧数和累计体积。
- 离开页面、取消或识别结束立即停止摄像头；已完成页面的结果与脱敏身份在约 3 秒后清除。
- 断线后查询当前会话结果，不伪造成功，也不由前端提交可信员工身份、相似度或最终考勤时间。
- 登录状态和设备凭据由 HttpOnly Cookie 管理。前端不保存密码、会话令牌、人脸原图或特征向量到 localStorage。
- 普通写请求在 `/auth/csrf` 取得 CSRF token 后发送；登录退出后刷新 token。文件导出为真实后端响应。

## 识别联通与校准

公共页面先读取业务服务的设备与识别就绪状态，仅在设备已授权且服务端返回 `ready=true` 时提供开始按钮。未授权、模型未就绪、人员库不同步或参数未校准时，按页面原因处理后点击“刷新设备状态”；每次开始前还会重新检查。浏览器不自行判断识别通过，也不替代服务端校验打卡时段。

录入人脸、同步人员库与授权设备不是完成校准的证明。默认 0.50 阈值、0.08 分差只是工程初值，不能直接勾选“已校准”。应先使用独立样本生成真实校准报告，再填写参数并确认。修改阈值或分差会清除当前表单的旧校准确认；保存为未校准状态后，服务端继续拒绝公共打卡。算法采样与校准方法见项目根目录的算法说明。

## 验证边界

`pnpm build` 执行完整 Vue/TypeScript 类型检查与生产打包。`pnpm test` 检查传输帧数、体积和超时边界、公共身份脱敏以及摄像头画面裁剪。真实浏览器摄像头权限、移动端受信任 HTTPS、算法识别效果和完整服务联调仍需按根目录验收清单在真实设备验证。依赖构建通过不等于真实人脸识别已跑通；前端没有模拟成功打卡或伪造统计数据。
